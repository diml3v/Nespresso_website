# Projektbeskrivelse

* Byg en enkel, responsiv hjemmeside om én Nespresso-kaffekapsel.
* Hjemmesiden skal bestå af præcis én forside og to undersider.
* Alle sider skal fungere på både mobil og desktop.

# Teknologier

* Brug HTML5 og CSS3.
* Brug semantisk HTML.
* Brug ikke JavaScript, backend-programmering, frameworks, tredjepartsbiblioteker eller build-værktøjer.

# Projektstruktur

* Behold HTML-filer i projektets rod og CSS samt billeder under `assets/`:

```text
projekt/
├── AGENTS.md
├── index.html
├── flavor-profile.html
├── brewing-guide.html
└── assets/
    ├── css/
    │   └── styles.css
    └── images/
```

* Brug relative filstier, og opret kun nødvendige filer.

# Arbejdsform

* Undersøg den eksisterende kode og projektstruktur før ændringer.
* Ændr kun relevante filer, og lav færrest mulige ændringer.
* Bevar fungerende kode og eksisterende konventioner.
* Spørg kun, hvis manglende information har væsentlig betydning for resultatet.

# Andre vigtige ting i projektet

* Brug engelske navne til nye filer, CSS-klasser og andre kodeidentifikatorer.
* Skriv al synlig tekst på dansk.
* Brug den samme tydelige navigation på alle tre sider.
* Sørg for, at alle navigationslinks virker.
* Giv meningsfulde billeder beskrivende `alt`-tekst.

# Begrænsninger

* Arbejd kun i projektmappen.
* Flyt, omdøb eller slet ikke eksisterende filer uden godkendelse.
* Tilføj ikke funktioner, produktdata eller designvalg, som ikke er aftalt.
* Brug kun lokale billeder fra projektets billedmappe.
* Gem aldrig adgangskoder, API-nøgler eller andre følsomme oplysninger i koden.

# Test og kvalitet

* Kontrollér HTML, CSS, relative filstier og alle navigationslinks.
* Test hjemmesiden på mobil- og desktopbredde.
* Kontrollér tastaturbetjening, synlig fokusmarkering og tilstrækkelig farvekontrast.
* Kontrollér, at indholdet er forståeligt, og at designet er ensartet på alle sider.

# Svar fra CODEX

* Svar kort og konkret på dansk.
* Angiv ændrede filer og udførte tests.
* Oplys om eventuelle fejl, risici eller forhold, der ikke kunne testes.
